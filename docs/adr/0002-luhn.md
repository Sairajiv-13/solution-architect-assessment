# 0002. Require a checksum for card candidates

Redact 13 to 19 digit candidates that pass Luhn. The scanner tests digit-group boundaries so it can recognize a spaced card near another number. This preserves many order IDs that the previous length-only check masked.

Luhn is a checksum. Some unrelated IDs pass it, and a malformed card can fail it. A [separate rule](0006-compact-ssns.md) covers SSNs. Candidates above the scanner's buffer cap still fail closed, even if their final checksum would fail.
